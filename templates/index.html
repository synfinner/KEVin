Endpoints

Method Path Returns
GET /kev Latest entries
GET /kev/{cve} One KEV record
GET /kev/exists?cve= Whether a CVE is in the catalog
GET /kev/recent?days= Added in the last N days
GET /kev?search= Keyword, ransomware, actor, and sort filters
GET /vuln/{cve} CVE details
GET /vuln/{cve}/nvd NVD record
GET /vuln/{cve}/mitre MITRE record
GET /vuln/published?days= CVEs published in the last N days

List routes accept page and per_page. Search covers KEV records only.

2 requests per second per IP. Violations are blocked for one hour. Cached responses can lag the catalog by up to 3 hours.
